# Birds aint Birding
<br>

Birds aint birding is my first Godot game made for [Haven-jumpstar](haven.jumpstart.hackclub.com) by HackClub. You are a small yellow bird and you gotta find your way through the blue world to find the exit. 

## Keys to play:

Movement: AD/left & right arrow keys

Jump: Space/W/up key

Sprint: Shift
